# GlobalTools organic marketing system

- scripts/marketing-robot.js creates a daily multilingual promotion pack in marketing/queue.json.
- marketing-center.html provides platform-specific drafts, tracked links and one-click copy/share actions.
- The existing SEO workflow runs the marketing generator and commits the daily pack. Run it manually in GitHub Actions for an immediate refresh.
- UTM parameters identify referring channel, campaign and language in analytics.

Open after deployment: https://globaltoolsnow.com/marketing-center.html

Important: this is an organic distribution assistant, not a universal auto-poster. Social platforms require account authorization and may restrict API publishing. It does not scrape users, create accounts, send unsolicited DMs/emails, buy engagement or auto-post without explicit account connection and permission. Publish manually from your own accounts and follow each community's rules.

Free channels to work through: Product Hunt, relevant Reddit communities, LinkedIn, X, Pinterest, Facebook, WhatsApp, Telegram, Hacker News Show HN, Indie Hackers, AlternativeTo and SaaSHub. Availability and eligibility can change; review each platform before submitting.
